# Ediflex

Starter responsive para Ediflex construido con React, Vite y TypeScript.

Esta fase incluye únicamente la base visual, navegación hash del lado del cliente y pantallas placeholder. Momen, GraphQL y autenticación se configurarán después.

## Requisitos

- Node.js LTS compatible con la versión de Vite instalada.
- npm.

## Instalación y desarrollo

```bash
npm install
npm run dev
```

Vite mostrará la URL local en la terminal, normalmente `http://localhost:5173`.

## Verificación

```bash
npm run typecheck
npm run build
npm run preview
```

No hay ninguna dependencia, variable de entorno ni conexión de Momen en este starter.
